# CognoDB Job Recommendation System

A graph-based job recommendation system that recommends jobs to users based on their skills.

## Features

- User-based job recommendations
- Skill matching
- Job search
- Job details
- Salary information
- Experience information
- CognoDB graph database integration
- React frontend
- Node.js and Express backend

## Technologies

- React
- JavaScript
- Node.js
- Express.js
- CognoDB
- Cypher
- Vite

## Architecture

React Frontend
        ↓
Express Backend
        ↓
Controllers
        ↓
Services
        ↓
CognoDB
